## 2. Efeitos "bioquímica e tecnologia" (16), adaptados à marca

Paleta em todos: fundo noite **#0F1C2C**, dourado **#A07F45 → #D9C78E → #F4F2BE**, gelo **#F3F5F8**, dourado de texto no
gelo **#7E6131**. O dourado é o "material" (átomo, partícula, gota, linha de dado); o resto fica em noite ou gelo.
Nos prompts de imagem e vídeo, escrever em inglês costuma dar resultado melhor (relato do Hora de Codar), sempre com
"no text, no packaging, no capsule, no pill, no bottle".

### E1. Estrutura molecular 3D girando
- **Código:** 3Dmol.js lê um composto direto do PubChem pelo número (CID) e gira sozinho:
```html
<script src="https://3Dmol.org/build/3Dmol-min.js"></script>
<div class="viewer_3Dmoljs" style="width:900px;height:900px" data-cid="586"
     data-style="stick" data-spin="axis:y;speed:10" data-backgroundcolor="0x0F1C2C"></div>
```
  Para o motor (quadro a quadro), trocar o `data-spin` por rotação calculada a partir de `t`. Cor dourada nos bastões
  pela API de estilo. CID 586 = creatina (conferido no PubChem).
- **Claude Design/Motion:** "Molécula de creatina em bastões dourados sobre #0F1C2C, gira 40° em 4 s, câmera se aproxima
  1,0 → 1,15; rótulo C4H9N3O2 entra depois". Anexar o SMILES.
- **IA de vídeo:** não usar: o Runway e o Kling inventam ligações e átomos. Molécula sempre em código.
- **Referência:** [3Dmol embutido](https://3dmol.csb.pitt.edu/doc/tutorial-embeddable.html) [busca].

### E2. Fórmula estrutural que se desenha (traço a traço)
- **Código:** SmilesDrawer desenha a fórmula a partir do SMILES, em SVG; as ligações saem como `<line>` e os rótulos dos
  átomos como `<text class="element">` (conferido no código-fonte). Dá para animar ligação por ligação:
```js
// SMILES do PubChem: https://pubchem.ncbi.nlm.nih.gov/rest/pug/compound/name/creatine/property/SMILES,MolecularFormula,MolecularWeight/JSON
const tema = { C:'#D9C78E', O:'#F4F2BE', N:'#F4F2BE', H:'#D9C78E', BACKGROUND:'#0F1C2C' };
const d = new SmilesDrawer.SvgDrawer({ width: 900, height: 900, themes: { bmg: tema } });
SmilesDrawer.parse('CN(CC(=O)O)C(=N)N', arv => d.draw(arv, 'mol', 'bmg'));
// depois de desenhar: cada ligação nasce em sequência
document.querySelectorAll('#mol line').forEach((l, i) => {
  const L = Math.hypot(l.x2.baseVal.value - l.x1.baseVal.value, l.y2.baseVal.value - l.y1.baseVal.value);
  l.style.strokeDasharray = L; l.style.strokeDashoffset = L;
  l.style.animation = `liga .35s cubic-bezier(.16,1,.3,1) ${i * 0.06}s forwards`;
});
// @keyframes liga { to { stroke-dashoffset: 0 } }  · rótulos (text.element) entram com opacidade no fim
```
- **Uso:** nome do ativo + fórmula molecular + "massa molar 131,13 g/mol" (dado do PubChem, com fonte na tela).
- **Referência:** [SmilesDrawer](https://github.com/reymond-group/smilesDrawer) [aberto] · [API do PubChem](https://pubchem.ncbi.nlm.nih.gov/rest/pug/compound/name/creatine/property/SMILES,MolecularFormula,MolecularWeight/JSON) [aberto].

### E4. Partículas que formam palavra, número ou mapa
- **Código:** desenhar o alvo (palavra, "95%", contorno da Bahia) num canvas fora da tela, amostrar os pixels acesos e dar a
  cada partícula uma origem aleatória **com semente** e um destino:
```js
function alvos(texto, passo = 6) {                    // 1080×1920
  const c = new OffscreenCanvas(1080, 1920), g = c.getContext('2d');
  g.font = '700 420px Poppins'; g.textAlign = 'center'; g.fillText(texto, 540, 1000);
  const px = g.getImageData(0, 0, 1080, 1920).data, pts = [];
  for (let y = 0; y < 1920; y += passo) for (let x = 0; x < 1080; x += passo)
    if (px[(y * 1080 + x) * 4 + 3] > 128) pts.push([x, y]);
  return pts;
}
// quadro t: p = ease(clamp((t - atraso_i) / 1.2)); x = lerp(origem_i.x, alvo_i.x, p) ...
// atraso_i = 0 a 0,4 s conforme a distância; ease = cubic-bezier(.16,1,.3,1); 3 a 5 mil pontos de 2–3 px
```
- **Variação nova:** a partícula **sai de uma palavra e forma a seguinte** ("pó" → "fórmula"), sem corte.
- **Referências:** TomBener (4.844 partículas formam CLAUDE) [aberto](https://github.com/TomBener/claude-motion-reel/tree/main) ·
  `milestone-reveal` do Charlie Hills [aberto](https://github.com/charlie947/motion-graphics-skills) ·
  Codrops, partículas GPGPU [busca](https://tympanus.net/codrops/2024/12/19/crafting-a-dreamy-particle-effect-with-three-js-and-gpgpu/) ·
  estética de Refik Anadol [aberto](https://www.instagram.com/refikanadol/).

### E10. Holograma (ficha técnica flutuando)
- **Código (CSS):** listras horizontais finas + borda mais clara que o centro (o "Fresnel" de pobre) + tremida rara:
```css
.holo{ color:#F4F2BE; background:repeating-linear-gradient(0deg, rgba(217,199,142,.10) 0 2px, transparent 2px 6px);
  box-shadow: inset 0 0 60px rgba(244,242,190,.25), 0 0 24px rgba(217,199,142,.25); mix-blend-mode:screen }
/* listras descem 6 px por quadro; a cada ~3 s, 2 quadros com translateX(3px) e opacidade .85 (o "glitch raro") */
```
- **Código (three.js):** a aula de holograma do Three.js Journey: Fresnel (borda acesa, centro apagado), listras no
  fragment shader e glitch no vertex shader que só dispara em poucos casos (`step(0.97, ...)`).
- **Uso:** a ficha do ativo (fórmula molecular, massa molar, origem) aparece como holograma sobre o fundo macro.

## 3. Dez formatos novos (carrossel e microreel)

Cada um tem regra fixa (para virar série) e um "brinquedo" diferente. Todos sem cápsula, sem produto, sem antes e depois.

### F1. "A molécula que se monta" (microreel 12–15 s ou carrossel animado)
- **Como é:** 0–1,5 s: poeira dourada solta na tela noite. 1,5–4 s: os pontos se juntam nos átomos (E4) e as ligações se
  desenham uma a uma (E2). 4–6 s: a molécula gira em 3D (E1). Depois: nome do ativo, fórmula molecular, uma frase
  aprovada (IN 28 literal quando houver) e fonte. Fecha no cartão final.
- **Carrossel:** slide 1 só a poeira + gancho ("O que é, de verdade, a creatina?"); slides 2–4 a montagem em 3 estados;
  slide 5 a ficha (fórmula, massa molar, onde o corpo produz).
- **Referência:** partículas que formam palavra (TomBener) [aberto](https://github.com/TomBener/claude-motion-reel/tree/main) ·
  pontos que viram o número (`milestone-reveal`) [aberto](https://github.com/charlie947/motion-graphics-skills).
- **Série:** creatina, glicina (do bisglicinato), colecalciferol, ácido ascórbico, cafeína. SMILES sempre do PubChem.

### F2. "Do pó à fórmula" (zoom contínuo, microreel 10–12 s)
- **Como é:** abre no macro do pó dourado (E7). A câmera recua sem cortar: o pó vira um monte na balança, a balança vira um
  ponto na bancada, a bancada vira um ponto no mapa de Santaluz, o mapa vira o pino do cartão final. Texto mínimo, uma
  palavra por escala ("Pó · Pesagem · Fórmula · Santaluz-BA").
- **Sem pessoas inventadas e sem produto:** a bancada pode ser foto real da unidade ou ilustração em linha (E11).
- **Referência:** o zoom infinito do Paul Trillo para o Washed Out [busca](https://nofilmschool.com/ai-music-video) ·
  ganchos "eye zoom" e "satellite swoop" do Higgsfield [aberto](https://dealroom.co/news/135584-how-higgsfield-scaled-to-a-400m-run-rate-in-13-months/).
- **Como fazer:** cenas em código encaixadas (E14) e, se quiser o macro real, Veo "Frames to Video" entre o pó e a bancada.

### F3. "Raio X do rótulo" (carrossel 6–7 slides ou microreel 15 s)
- **Como é:** um rótulo **tipográfico** de fórmula manipulada (sem frasco, só a etiqueta chapada no fundo gelo, dados
  fictícios e marcados como exemplo) com campos: paciente, prescritor, composição, lote, data, validade, farmacêutico
  responsável e CRF-BA. A lente de raio X (E9) passa campo por campo e, dentro dela, aparece o que aquele campo significa.
- **Por que é forte:** é educação pura ("saiba ler o seu rótulo"), cabe na propaganda institucional, mostra rigor e não
  anuncia produto.
- **Referência:** raio X com máscara de fluido do Codrops [aberto](https://engineered.at/articles/building-a-dual-scene-fluid-x-ray-reveal-effect-in-three-js) ·
  lente que segue o cursor [busca](https://tympanus.net/codrops/?p=119046).
- **Conferir com a farmacêutica:** quais campos o rótulo da unidade tem de fato.

### F4. "Matéria-prima × fórmula liberada" (o "antes do laboratório × depois", sem a palavra "antes e depois")
- **Como é:** tela dividida que **fala de processo, nunca de resultado em pessoa**: em cima, o insumo chegando (pó a
  granel, laudo, etiqueta "QUARENTENA"); embaixo, o mesmo plano com a luz da liberação (etiqueta "APROVADO", pesagem
  conferida). Um só plano, dois estados, como no "mesmo lugar, outra luz".
- **Como fazer:** Runway Aleph 2.0 muda luz e estado de um plano real gravado na unidade (até 30 s, 1080p), ou Veo
  "Frames to Video" entre duas fotos reais. Título: "Do laudo à liberação". **Nunca** escrever "antes e depois" (vedado
  na publicidade, item 4 das regras).
- **Referência:** [Aleph 2.0 e Edit Studio](https://runway.com/news/introducing-aleph-2-and-edit-studio) [busca] ·
  [Veo 3.1](https://blog.google/technology/ai/veo-updates-flow/) [busca].

### F5. "Linha do tempo do ativo" (carrossel panorâmico ou microreel 15–20 s)
- **Como é:** uma linha dourada fina atravessa os slides; cada estação é um marco (quem isolou, quando a estrutura foi
  descrita, quando virou recomendação). Em cada estação, a molécula (E2) ganha uma parte. No fim, a molécula inteira.
- **Diferente do C4 anterior** (linha do tempo do processo): aqui é **a história da ciência do ativo**, que dá
  autoridade sem prometer efeito.
- **Referência:** formato "explicador estilo documentário" (skill `vox-explainer`) [aberto](https://github.com/charlie947/motion-graphics-skills) ·
  Claude Motion para "transformar um relatório num explicador de 30 s" [aberto](https://support.claude.com/en/articles/17454997-get-started-with-claude-motion).
- **Cuidado:** cada data com fonte na tela (artigo ou livro). Nenhuma data entra sem conferência.

### F6. "A Bahia em 417 pontos" (mapa com entregas, microreel 10–12 s)
- **Novo em relação ao estudo anterior (C6, R10):** a malha oficial do IBGE já está localizada:
  `https://servicodados.ibge.gov.br/api/v3/malhas/estados/29?formato=application/vnd.geo+json&intrarregiao=municipio`
  (URL-base e parâmetros na documentação; gerar a URL final no "Query Builder" da página e testar antes)
  [aberto](https://servicodados.ibge.gov.br/api/docs/malhas?versao=3).
- **Como é:** cada um dos 417 municípios vira **um ponto dourado** (centroide pelo `d3.geoPath().centroid`); os pontos
  nascem da poeira (E4) e formam a Bahia; Santaluz acende com halo; depois, linhas finas saem de Santaluz em ondas
  ("Entrega grátis para toda a Bahia"). Exceção dos controlados no aviso.
- **Referência:** estética de dados em partículas de Refik Anadol [aberto](https://www.instagram.com/refikanadol/).

### F7. "O elemento" (série tabela periódica, carrossel 5 slides ou microreel 8–10 s)
- **Como é:** um ladrilho de tabela periódica em dourado sobre noite (símbolo grande, número atômico, massa): **Mg 12,
  Zn 30, Fe 26, Ca 20, Se 34**. A câmera mergulha no ladrilho (T6 do estudo anterior) até um átomo em wireframe (E11)
  com as camadas de elétrons em órbita; a órbita externa vira o anel da marca. Depois: uma função aprovada pela IN 28 e a
  fonte.
- **Por que é forte:** é instantaneamente "química", vira coleção (o público espera o próximo elemento) e não tem nada de
  produto. A tipografia é Poppins pura, sem ilustração.
- **Referência:** dados do elemento no PubChem (mesma API do E2) e a regra "um elemento visual novo por episódio" do
  estudo anterior (Beetroot/SPL). Formato de série com moldura fixa: [Fala IA!](https://github.com/alexalmeida70/criador-de-carrosseis-simples) [aberto].

### F8. "Microscópio de bolso" (carrossel de zoom 1× → 10× → 40× → 125×)
- **Como é:** slide 1, o pó numa colher de pesagem (foto real ou macro do ChatGPT); cada slide aumenta a escala com uma
  régua no canto ("10×", "40×"); no último, o cristal sob luz polarizada em duotone dourado (E3) e o fato ("a vitamina C
  forma cristais assim quando recristaliza"). Ao arrastar, parece que a pessoa gira a objetiva.
- **Referência:** galeria de cristais de vitaminas do Nikon Small World (só referência visual)
  [busca](https://nikonsmallworld.com/galleries/2019-photomicrography-competition/vitamin-c).
- **Microreel:** a mesma coisa como zoom contínuo (E14) com troca de foco a cada escala.

### F9. "O laudo que se escreve" (microreel 12–15 s)
- **Como é:** a tela vira um documento técnico em gelo; os campos de um **certificado de análise genérico** se preenchem
  (identificação, aspecto, teor, data) com os dígitos girando (T7 do estudo anterior); uma linha de gráfico de análise se
  desenha (pico, linha de base); cada campo ganha um visto dourado. Fecha com "Cada lote de matéria-prima chega com
  laudo. E é conferido." e "RDC 67/2007".
- **Referência:** gráfico animado que mantém os valores exatos (`animated-chart`) [aberto](https://github.com/charlie947/motion-graphics-skills).
- **Conferir com a farmacêutica:** quais ensaios aparecem nos laudos que a unidade recebe e quais ela mesma faz. Não
  insinuar análise que a unidade não faz. Dados do laudo na tela são **exemplo**, marcado como tal.

### F10. "Ficha holográfica do ativo" (microreel 8–10 s, ótimo como loop de carrossel animado)
- **Como é:** sobre o fundo macro do ativo (E7: cristal para magnésio, gota para ômega-3), a molécula em wireframe
  dourado (E1 + E11) gira dentro de um holograma (E10). Três linhas de dado entram ao lado, uma por batida: fórmula
  molecular · massa molar · "onde está na natureza". Glitch raro (E16) no corte final.
- **Referência:** aula de holograma (Fresnel + listras + glitch raro) [busca](https://threejs-journey.com/lessons/hologram-shader) ·
  wireframe e loops do TomBener [aberto](https://github.com/TomBener/claude-motion-reel/tree/main).

## 4. Como encaixar no que já existe

1. **Primeiro os formatos que só pedem código** (F1, F7, F6, F10): saem do `motor/` sem depender da fila do ChatGPT nem
   do Runway. Novos tipos de cena sugeridos: `molecula` (E1/E2), `particulas` (E4/E5), `raiox` (E9), `holo` (E10),
   `elemento` (F7), `mapa417` (F6). Todos com render por `t`.
2. **Pedidos para a gestão gerar** (pasta `conteudo/runway/`): 5 fundos macro (E7), 3 cristais (E8), 2 tintas douradas (E6),
   cada um com o prompt-base, uma câmera só, 4–6 s, sem texto. Marcar o rótulo de IA no post.
3. **Claude Motion:** conferir se o plano do Claude é Team. Se for, testar F5 e F9 (linha do tempo e laudo) por lá: é o
   uso oficial (dados anexados → explicador em MP4).
4. **Seguir de perto (Instagram):** @higgsfield.creators e @runway.creators (repostam o que está funcionando),
   @refikanadol (dados), @paultrillo (câmera), @mjay.ai (acabamento brasileiro).
5. **Não usar:** Sora (desligado), molécula gerada por IA de vídeo (erra a química), pessoa gerada por IA (regra da
   L'Oréal e da publicidade em saúde), qualquer "antes e depois".
